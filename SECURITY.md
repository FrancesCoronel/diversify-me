# Security Policy

## Supported Versions

Only the latest version of [DiversifyMe](https://francescoronel.github.io/diversify-me/), built from `master`, is maintained.

## Reporting a Vulnerability

Please **do not** open a public issue for security problems.

Instead, use one of these:

- **GitHub Private Vulnerability Reporting** (preferred): use the [Report a vulnerability](https://github.com/FrancesCoronel/diversify-me/security/advisories/new) button on the Security tab.
- **Email**: [frances@francescoronel.com](mailto:frances@francescoronel.com)

Please include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

I aim to respond within **72 hours** and will keep you updated while the issue is investigated and fixed.

## Scope

In scope: the DiversifyMe site and the content in this repository.

Out of scope: the conference sites the list links to, denial of service, and social engineering.
